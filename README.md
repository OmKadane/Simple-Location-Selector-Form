# 🌍 Premium Simple Location Selector Form

A premium, modern, and highly user-friendly location selector form built with **React**, **Vite**, and styled with **Vanilla CSS**. This component provides searchable dropdowns for selecting any Country, State/Province, and City in the world, backed by complete real-world data coverage.

## ✨ Features

- 🌐 **Comprehensive Data:** Accurate and up-to-date countries, states, and cities globally using the reliable `country-state-city` package.
- 🔍 **Interactive Search:** Smooth filterable dropdown fields to search countries, states, and cities effortlessly.
- 🧼 **Clean Custom Scrollbar:** Custom minimalist scrollbar on dropdowns that perfectly complements the card's aesthetics.
- 🎯 **Aesthetic UI:** Premium modern sizing, generous input fields, subtle shadows, and eye-appealing layout.
- ⚡ **Dynamic Selection:** Automatically guides the user step-by-step from Country to State/Province and then City.
- 🖱️ **Flawless Outside Click Close:** Clicking anywhere outside an active dropdown closes all open lists smoothly.
- 📱 **Fully Responsive:** Looks gorgeous on mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite 8
- **Data Source:** `country-state-city`
- **Styling:** Vanilla CSS (Modern, fluid typography, smooth transitions)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/OmKadane/Simple-Location-Selector-Form.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Simple-Location-Selector-Form
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Run the local development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.
